T062 / PS-045 - BUS RESERVATION SYSTEM

RUN FROM THE PROJECT ROOT (Windows CMD)

1) Compile:
   javac -d out src/model/*.java src/util/*.java src/service/*.java src/Main.java src/DataLoadTest.java

2) Test CSV loading:
   java -cp out DataLoadTest

3) Run the official 127-line command file:
   java -cp out Main input/T062-PS-045-sample-data/commands.txt

You can also run with no arguments:
   java -cp out Main

OUTPUT
The program creates these files in output/:
- tickets.csv
- command_results.csv
- trip_chart.csv
- partner_settlement.csv

The command_results.csv file contains one result per nonblank, noncomment command.
Its line_no is the original physical line number in commands.txt.
