
# Bus Reservation System

**Team ID:** T062  
**Problem Statement:** PS-045  
**Language:** Java

## Overview
A command-line bus reservation system designed to manage
routes, trips, seat inventory, passenger bookings, fares,
cancellations and rescheduling.

## Planned Features
- Routes, stops and departure times
- Bus layouts and seat types
- Stage-wise seat availability
- Passenger booking and fare calculation
- Child fare rules and ladies-seat restrictions
- Partial and full cancellation
- Booking rescheduling
- Tickets and trip charts
- Partner settlement and commission

## Requirements
- Java Development Kit (JDK)
- Command Prompt or terminal

## Run
Open a terminal inside the src folder.

Compile:
javac Main.java

Run:
java Main

## Current Status
Initial Java setup and basic booking demonstration.
Core business rules and automated tests are still in progress.
