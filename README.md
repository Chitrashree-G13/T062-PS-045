# T062-PS-045 – Bus Reservation System

## Project Overview

A Java command-driven bus reservation engine developed for **PS-045: Bus Reservation with Boarding Points, Seat Types and Partial Cancellation**.

The system processes ordered commands against CSV master data and generates four evaluation CSV output files.

**Team:** T062  
**Project Code:** PS-045  
**Domain:** Travel – Inter-city Bus Reservation  
**Programming Language:** Java 17+

## Features

- Ordered routes with multiple boarding and drop points.
- Stage-based seat inventory and seat availability management.
- Seater and sleeper seat layouts.
- Ladies-only seats and adjacent-berth protection.
- Stage fare calculation and seat premiums.
- Occupancy-based dynamic pricing.
- Child fare factors and GST calculation.
- Counter and partner bookings.
- Partner commission and cancellation-fee sharing.
- Passenger-level partial and full cancellation.
- Boarding-time-based cancellation refunds.
- One-time ticket rescheduling and fare difference calculation.
- Boarding-point changes.
- Operator trip cancellation.
- Ticket printing with fare breakup.
- Trip chart generation.
- Partner settlement generation.

## Requirements

- Java Development Kit (JDK) 17 or later.
- Python 3 for running the regression verification script.
- Windows Command Prompt or a compatible terminal.

## Compilation and Execution

Open the terminal in the main project folder.

### Step 1: Create the output directory for compiled classes

```cmd
if not exist out mkdir out
```

### Step 2: Compile the Java source files

```cmd
javac -d out src/model/*.java src/util/*.java src/service/*.java src/Main.java src/DataLoadTest.java
```

### Step 3: Verify master CSV data loading

```cmd
java -cp out DataLoadTest
```

The data-loading test displays the number of routes, buses, trips and partners loaded from the supplied master CSV files.

### Step 4: Run the bus reservation application

```cmd
java -cp out Main input/T062-PS-045-sample-data/commands.txt
```

The application processes the commands from the supplied command file and generates the required output CSV files in the `output` folder.

### Alternative: Specify Input, Command and Output Paths

```cmd
java -cp out Main input/T062-PS-045-sample-data input/T062-PS-045-sample-data/commands.txt output
```

## Running the Regression Tests

After compiling the Java files, execute:

```cmd
python tests/verify_project.py
```

The verification script uses Python's standard library and checks the official sample command file along with additional test scenarios.

The tests cover:

- The eight planted edge cases.
- Additional validation and rejection scenarios.
- CSV output headers and row ordering.
- Ticket printing and final-state behaviour.
- Partial cancellation and rescheduling combinations.
- Seat availability and seat reuse.
- Cancellation refund boundaries.
- Boarding-point change restrictions.
- Partner settlement and commission calculations.
- Operator cancellation scenarios.

**Latest recorded verification result: 50 passed, 0 failed.**

Refer to `docs/verification-report.md` for the verification details and limitations.

## Evaluation Output Files

The application generates the following four CSV files inside the `output` folder.

| File Name | Description |
|---|---|
| `tickets.csv` | Passenger-level ticket and booking details. |
| `command_results.csv` | Result of every physical non-comment command. |
| `trip_chart.csv` | Passenger and seat information generated by trip-chart commands. |
| `partner_settlement.csv` | Partner commission and settlement information. |

The column order follows the supplied sample-data README.

`PRINT_TICKET` displays the ticket with its fare breakup using the final end-of-file state. `PRINT_CHART` and `PRINT_SETTLEMENT` generate their corresponding CSV output rows.
