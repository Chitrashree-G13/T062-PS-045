
# Glossary – Bus Reservation System

| Term | Meaning |
|---|---|
| Route | An ordered sequence of stops followed by a bus. |
| Stop | A location where passengers can board or leave the bus. |
| Stage | The section of a route between two consecutive stops. |
| Trip | A bus journey on a particular route and travel date. |
| Bus | The vehicle assigned to operate a trip. |
| Bus Layout | The arrangement of seats and berths inside a bus. |
| Seat Type | The category of seat, such as seater, lower sleeper, upper sleeper or single sleeper. |
| Boarding Point | The stop where a passenger gets onto the bus. |
| Dropping Point | The stop where a passenger gets off the bus. |
| Seat Inventory | The record of seats available for each section of a trip. |
| Booking | A reservation made for one or more passengers. |
| Ticket | The record containing booking and passenger journey details. |
| Stage Fare | The sum of the fares for all stages between boarding and dropping points. |
| Seat Premium | The additional amount charged for a particular seat type. |
| Dynamic Pricing | Fare adjustment based on seat occupancy. |
| Occupancy | The proportion of seats already booked on a route stage. |
| Ladies Seat | A seat restricted to female passengers under the specified booking rules. |
| Partial Cancellation | Cancelling selected passengers without cancelling the entire booking. |
| Refund | The amount returned when a booking or passenger is cancelled. |
| Rescheduling | Moving a booking to another eligible trip. |
| GST | Goods and Services Tax applied according to the trip's tax rules. |
| Partner Channel | An external booking partner through which tickets may be sold. |
| Partner Commission | The commission paid to a partner for eligible bookings. |
| Trip Chart | A report showing passenger, seat and boarding/drop details for a trip. |
| Operator Cancellation | Cancellation of a trip by the bus operator. |
| Business Rule | A condition that defines how the reservation system must behave. |
| Stop Index | The position of a stop in the ordered route. |
| Decision Log | A record of important design decisions and their reasons. |
| Unit Test | A test that checks one specific part of the program. |
